Which core interaction makes communication essential?

Question. Three rough candidates for the cooperative game's core interaction. Play each one as both Players (click in either panel) and notice: does each Player hold something the other needs, does it work when you're saying it out loud, does it survive a phone-sized screen, could it fill 15–30 minutes with replays, and could it be built in about five days? State is in memory; nothing persists. "Referee view" at the bottom shows everything the server would know, secrets included, so you can cheat.
