# Crit 8 reflection

## What was the breakthrough that moved the work forward?

Realising that persistence changed the game itself, not just the storage. My
prototype had one fixed device: cut the second wire, press the symbols in the
same order every time. That was fine as a demo. But once every run was logged
and people could come back, a fixed device would have made the station log a
record of who memorised the answers fastest. Choosing randomised devices meant
rewriting the manual as general rules, and that's what made the Expert
actually ask questions. Keeping each rule's text next to its logic then turned
"is it fair?" into something a test can answer: one check plays a whole device
using only the manual.

## What did this work change about who I want to be as a software developer?

I spent the start of the session answering questions instead of writing
prompts for code, and those answers did more for the result than any code
review would have. Where I disagreed with the agent's recommendation, picking
React over vanilla JS or asking for both private rooms and solo tabs instead of
one or the other, I could say why. Those are the decisions I'll still be able
to defend at the crit. I want to be the developer who owns the decisions and
can explain them, and who uses the agent to get to a working version fast
enough that the decisions get tested by real people rather than argued about
in the abstract.
