# ADR 004 — No built-in voice or text chat

## Context
Communication is the game. Players need a channel.

## Options
1. WebRTC voice in-app.
2. Text chat in-app.
3. External: players use a phone/Discord call or sit together.

## Decision
External only. The README, home page and lobby say so plainly.

## Consequences
No TURN servers, permissions prompts or moderation. Text chat would let
players paste diagrams as text and flatten the interpretive challenge. The
cost: a solo marker must open two browser profiles and "talk to themselves";
the README explains how.
